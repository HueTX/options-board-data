Standing Rules

Operating rules set by Hubert — the system follows these without being asked twice.

Morning data freshness 2026-10-02

"I am tired of telling you what is wrong on the website. Here are the standing rules!"
  1. Every morning, check ALL panels ("pills") for accurate live data as of the current date. Hubert should NEVER have to report stale data — the system must catch it first.
  2. Polls and heartbeats are not decorative — they must ACTIVELY refresh stale data. If a poll or heartbeat finds stale data, it heals it on the spot (rebuild + push), not just log it.
  3. Before 7:30 AM CT, a secondary sweep verifies everything from rule 1 is accurate, so live data is ready for morning review.

All board data live by 07:30 CT 2026-10-02

"I need all the data before 7:30am to be always live! No more stale data or excuses. Fix the logic once and for all."
  • Every morning-critical feed must be fresh by 07:30 CT on NYSE trading days: watchlist (today), follow-through ignitions (yesterday), premarket snapshot (today), 15-min closes (exists — yesterday's final is correct pre-open), quotes (live).
  • "Live" before the open means the most recent correct data with the right date shown on every panel.
  • Enforced by the 07:20 CT morning-readiness sweep, which heals any stale feed automatically.

5-minute full-board refresh 2026-10-02

  • The whole website refreshes and pulls new data to all pills every 5 minutes, updating with new data until the session ends (15:05 CT).
  • Applies to both the standalone site and the hosted board.

Never sit idle 2026-09-25

"Rather than getting stuck and waiting on me, if you see that I'm taking too long to respond to you go ahead and do other things."
  • While waiting on Hubert for input, keep working every other front — never park the whole process on one pending reply.

Cross-market price discrepancies 2026-09-30

  • Retain qualifying cross-market price discrepancies and show both prices with both sources — a discrepancy can be a good deal, never suppress it.
